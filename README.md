# Sentiment Analyzer

Python tool that takes text input and classifies the sentiment as positive, negative, or neutral using TextBlob's polarity scoring.

## Tech Stack
Python · TextBlob · Streamlit

## Run Locally
pip install -r requirements.txt
streamlit run textfilter.py

## What it does
- Accepts free text input from the user
- Returns sentiment score and classification
- Classifies sentiment using TextBlob's polarity scoring
